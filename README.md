# Pair_Programming

페어프로그래밍 실습으로 만든 **공튀기기** 게임입니다. 라이브러리·빌드 도구 없이 HTML Canvas와 바닐라 JS로만 만들었습니다.

## 실행

로컬에서는 `index.html`을 브라우저로 열면 됩니다.

**퍼블리시된 페이지 (Claude Artifact)**
<https://claude.ai/code/artifact/22f0e54d-2f6f-44d8-9ed8-956433cec270>

> 이 링크는 기본적으로 **비공개**입니다. 다른 사람이 열려면 아티팩트 페이지의 공유 메뉴에서 공유를 켜야 합니다.
> 게임 로직은 `index.html`과 동일하고, 페이지 디자인(오락실 캐비닛 프레임)만 다릅니다.

## 조작법

| 동작 | 입력 |
| --- | --- |
| 공 소환 | 게임 화면 클릭 (최대 5개) |
| 바 이동 | `←` `→` 또는 `A` `D` |
| 다시하기 | 게임오버 화면의 다시하기 버튼 |

## 규칙

- 클릭한 지점에서 공이 생성되어 등속 직선으로 움직입니다.
- 좌·우·천장 벽에 부딪히면 반사각으로 튕깁니다.
- 바에 맞으면 **맞은 지점에 따라 반사각이 달라집니다**. 중앙에 맞으면 수직에 가깝게, 끝으로 갈수록 옆으로 크게 (최대 60°) 튕깁니다.
- 바에 튕길 때마다 **1점**.
- 화면에 **공이 하나뿐일 때는 점수가 오를수록 공이 점점 빨라집니다** (1점당 14px/s, 최대 720px/s). 공을 하나라도 더 소환하면 기본 속도로 돌아갑니다.
- 공이 하나라도 화면 하단을 지나치면 **게임 오버**.
- 최고 점수는 `localStorage`에 저장되어 다음 판에도 유지됩니다.

## 설정값

`index.html`의 `BAR` / `BALL` 상수로 난이도를 조절할 수 있습니다.

| 값 | 기본값 | 설명 |
| --- | --- | --- |
| `BAR.width` | 120 | 바 너비 |
| `BAR.speed` | 520 | 바 이동 속도 (px/s) |
| `BALL.speed` | 340 | 공 기본 속도 (px/s) |
| `BALL.speedStep` | 14 | 공이 하나일 때 1점당 빨라지는 정도 (px/s) |
| `BALL.maxSpeed` | 720 | 속도 상한 (px/s) |
| `BALL.maxCount` | 5 | 동시에 존재할 수 있는 공 개수 |
| `BALL.maxBounceAngle` | 60° | 바 끝에 맞았을 때 튕기는 최대 각도 |

## 디버깅

브라우저 콘솔에서 `__game`으로 내부 상태를 볼 수 있습니다.

```js
__game.balls      // 현재 공 목록
__game.state      // { playing, score, hiScore }
__game.update(1/60)  // 한 프레임 수동 진행
__game.currentSpeed() // 지금 공의 목표 속력
```
